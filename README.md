## version control for the [esquemático site](https://esquematico.azurewebsites.net/Inicio) 

#### The purpose of this site is to provide detailed and comprehensive documentation for [esquemático](https://github.com/klfarran/scheme-traductor.git), a collection ot Racket macros which supports Scheme programming using Spanish keywords and Spanish error codes 

#### Built using ASP.NET .NET Framework, HTML/CSS, JavaScript, Bootstrap, Prism.js, deployed with Microsoft Azure
