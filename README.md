# Version Control for the [esquemático site](https://esquematico.azurewebsites.net/Inicio) 

### The purpose of this site is to provide detailed and comprehensive documentation for [esquemático](https://github.com/klfarran/scheme-traductor.git), a collection ot Racket macros which supports Scheme programming using Spanish keywords and Spanish error codes 

#### This site includes content in [English](https://esquematico.azurewebsites.net/Home) and [Spanish](https://esquematico.azurewebsites.net/Inicio)

#### Included in this site are
- Syntax patterns, descriptions, and examples for all procedures provided in esquemático
- Installation instructions for esquemático in [English](https://esquematico.azurewebsites.net/Download) and [Spanish](https://esquematico.azurewebsites.net/Descargar)
- A [tutorial](https://esquematico.azurewebsites.net/EmpezarAquí) to get started with your first esquemático program 

<br> 

#### Built using ASP.NET .NET Framework, HTML/CSS, JavaScript, Bootstrap, Prism.js
#### Deployed with Microsoft Azure
